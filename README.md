# Three Dimension View

A standalone, local-first house-scanning and 3D-viewing application for WiseStay.

## Owner requirements

- Vue.js single-page application (SPA), without React or Ionic Framework UI.
- Use the owner-supplied, purchased Suha mobile Nuxt template as the visual foundation for all application views.
- Capture and reconstruct on the phone, without a reconstruction server, on supported devices.
- Provide explicit capability and failure states; never present a camera preview, sample model, or photographs as a completed 3D scan.
- Test changes, merge them into `main`, and remove only branches whose work is preserved.

Implementation is being prepared on a dedicated development branch. This initial repository document is not a completion or device-qualification claim.

The purchased template archive and unrelated e-commerce demonstration assets must not be redistributed from this repository. Integrated template-derived styling remains subject to the owner's applicable Suha/Envato licence; this repository does not relicense that material.
